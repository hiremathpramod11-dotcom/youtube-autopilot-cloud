Privacy Policy

Last Updated: November 2026

This Privacy Policy applies to the YouTube Automation Agent application ("we", "our", or "the application"). This application is an automated content production and YouTube scheduling platform operated by the channel owner.

1. Data We Access

Our application requests access to the Google YouTube Data API v3 (https://www.googleapis.com/auth/youtube.upload and related scopes) exclusively to:

  • Upload and schedule video content produced for the channel.
  • Upload custom thumbnails and video metadata (titles, descriptions, tags).
  • Check video upload status and scheduling timestamps.

2. Data Storage & Security

All authentication tokens (OAuth2 refresh and access tokens) are stored locally on the owner's secured server or encrypted GitHub Secrets. We do not sell, rent, or transfer any user data, video data, or channel credentials to any third parties.

3. Third-Party Services

Our application interacts with the following services:

  • YouTube Data API v3: Subject to the Google Privacy Policy.
  • Google AI Studio / Gemini API: Used solely for script ideation and procedural narration rendering.

4. Revoking Access

The channel owner may revoke the application's access to their Google account at any time via Google Account Security Permissions.

5. Contact Information

For any questions regarding this privacy policy, please contact the developer via GitHub: youtube-autopilot-cloud.
